# Oblique UAS Mission Planning Simulator

Developed for the Caltrans T4575 project.

## Features

- Flight planning
- Oblique/Nadir footprint simulation
- GCP & Checkpoint planning
- KMZ export
- Pre-flight accuracy assessment
- HTML/PDF report generation
- Scenario comparison

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
